title: "GET /v1/agents — List All Agents for Your API Key"

description: "GET /v1/agents — retrieve a paginated list of all agents associated with your API key. Supports cursor-based pagination and status filtering."
---

The list agents endpoint returns all agents associated with your API key, ordered by creation date descending (newest first). Results are paginated using a cursor-based scheme so that you can reliably iterate through large collections without missing entries or seeing duplicates as new agents are created. You can also filter by `status` to retrieve only active or inactive agents.

## Endpoint

```
GET https://api.universalagi.com/v1/agents
```

## Query Parameters

<ParamField query="limit" type="integer" default={20}>
  The maximum number of agent objects to return in a single response. Must be between `1` and `100`. **Default: `20`**.
</ParamField>

<ParamField query="cursor" type="string">
  An opaque cursor string returned in the `next_cursor` field of a previous response. Pass this value to retrieve the next page of results. Omit for the first request. Optional.
</ParamField>

<ParamField query="status" type="string">
  Filter agents by their current status. Accepted values: `"active"`, `"inactive"`. Omit this parameter to return agents of all statuses. Optional.
</ParamField>

## Response

<ResponseField name="data" type="array">
  An array of agent objects matching the query. Each object in the array has the same shape as the response from [Create Agent](/api-reference/agents/create).

  <ResponseField name="data[].id" type="string">
    Unique agent identifier, prefixed with `agent_`.
  </ResponseField>

  <ResponseField name="data[].name" type="string">
    Human-readable name of the agent.
  </ResponseField>

  <ResponseField name="data[].model" type="string">
    The model ID the agent is configured to use.
  </ResponseField>

  <ResponseField name="data[].status" type="string">
    Current status: `"active"` or `"inactive"`.
  </ResponseField>

  <ResponseField name="data[].created_at" type="string">
    ISO 8601 timestamp of agent creation.
  </ResponseField>
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if there are additional agents beyond this page, `false` if this is the last page. When `true`, use `next_cursor` to fetch the next page.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  An opaque cursor string to pass as the `cursor` query parameter in your next request to retrieve the following page. `null` when `has_more` is `false`.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.universalagi.com/v1/agents?limit=10&status=active" \
  -H "Authorization: Bearer $UNIVERSALAGI_API_KEY"
```

```python Python
from universalagi import UniversalAGI

client = UniversalAGI()

# Fetch the first page of active agents
page = client.agents.list(limit=10, status="active")

for agent in page.data:
    print(agent.id, agent.name)

# Paginate through all results
while page.has_more:
    page = client.agents.list(limit=10, status="active", cursor=page.next_cursor)
    for agent in page.data:
        print(agent.id, agent.name)
```

```javascript JavaScript
import UniversalAGI from 'universalagi';

const client = new UniversalAGI();

let page = await client.agents.list({ limit: 10, status: 'active' });

for (const agent of page.data) {
  console.log(agent.id, agent.name);
}

// Paginate through all results
while (page.hasMore) {
  page = await client.agents.list({ limit: 10, status: 'active', cursor: page.nextCursor });
  for (const agent of page.data) {
    console.log(agent.id, agent.name);
  }
}
```

<Note>
  Cursors are opaque and should be treated as strings — do not attempt to parse or modify them. Cursors expire after 10 minutes; if you need to resume pagination after a long pause, restart from the beginning.
</Note>
