title: "POST /v1/agents/{id}/run — Run an Agent on a Task"
sidebarTitle: "Run Agent"
description: "POST /v1/agents/{id}/run — submit an input task for the agent to execute. Returns a run object with status, output, and step-by-step execution details."
---

Once you have [created an agent](/api-reference/agents/create), you run it by submitting a natural-language task as input. The agent will autonomously plan how to complete the task, calling its configured tools across as many steps as needed, and then produce a final output. The run object returned by this endpoint includes the full output as well as a step-by-step trace of every tool invocation, making it straightforward to audit what the agent did and why.

## Endpoint

```
POST https://api.universalagi.com/v1/agents/{id}/run
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the agent to run. This is the `id` value returned when you [created the agent](/api-reference/agents/create), prefixed with `agent_`.
</ParamField>

## Request Body

<ParamField body="input" type="string" required>
  The task or question you want the agent to work on. Write this as you would a natural-language instruction. The agent will receive this as the first user message in addition to its configured `system_prompt`.
</ParamField>

## Response

<ResponseField name="id" type="string">
  The unique identifier for this run. Prefixed with `run_`. Use this ID to retrieve run details later if needed.
</ResponseField>

<ResponseField name="agent_id" type="string">
  The ID of the agent that executed this run.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the run. Possible values:
  - `"pending"` — the run has been queued but has not yet started.
  - `"running"` — the agent is actively working on the task.
  - `"completed"` — the agent has finished and produced an output.
  - `"failed"` — the run encountered an unrecoverable error.
</ResponseField>

<ResponseField name="input" type="string">
  The task input exactly as submitted.
</ResponseField>

<ResponseField name="output" type="string | null">
  The agent's final response to the task. `null` if the run has not yet completed or has failed.
</ResponseField>

<ResponseField name="steps" type="array">
  An ordered list of every reasoning step and tool invocation the agent performed during the run. This trace is useful for debugging agent behaviour and understanding how it arrived at its answer.

  <ResponseField name="steps[].index" type="integer">
    One-based step number indicating the order of execution.
  </ResponseField>

  <ResponseField name="steps[].tool" type="string">
    The name of the tool invoked in this step (e.g. `"code_runner"`, `"calculator"`). If the step was a pure reasoning step with no tool call, this field may be `null`.
  </ResponseField>

  <ResponseField name="steps[].tool_input" type="object | null">
    The arguments passed to the tool, as a JSON object. Shape depends on the tool. `null` for reasoning-only steps.
  </ResponseField>

  <ResponseField name="steps[].tool_output" type="string | null">
    The raw output returned by the tool after execution. `null` for reasoning-only steps.
  </ResponseField>

  <ResponseField name="steps[].summary" type="string">
    A concise human-readable description of what happened in this step, generated by the agent.
  </ResponseField>
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the run was initiated.
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  ISO 8601 timestamp of when the run reached a terminal state (`"completed"` or `"failed"`). `null` if still in progress.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl https://api.universalagi.com/v1/agents/agent_7f8e9d0c/run \
  -H "Authorization: Bearer $UNIVERSALAGI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "Analyze the sales data for Q3 and identify the top 3 performing regions."
  }'
```

```python Python
from universalagi import UniversalAGI

client = UniversalAGI()

run = client.agents.run(
    agent_id="agent_7f8e9d0c",
    input="Analyze the sales data for Q3 and identify the top 3 performing regions.",
)

print(run.output)
for step in run.steps:
    print(f"Step {step.index}: [{step.tool}] {step.summary}")
```

```javascript JavaScript
import UniversalAGI from 'universalagi';

const client = new UniversalAGI();

const run = await client.agents.run('agent_7f8e9d0c', {
  input: 'Analyze the sales data for Q3 and identify the top 3 performing regions.',
});

console.log(run.output);
run.steps.forEach(step => {
  console.log(`Step ${step.index}: [${step.tool}] ${step.summary}`);
});
```
</CodeGroup>

**Request body:**
```json
{
  "input": "Analyze the sales data for Q3 and identify the top 3 performing regions."
}
```

<Note>
  Run requests are synchronous by default — the HTTP connection remains open until the agent has finished or failed. For long-running tasks, consider setting a high HTTP client timeout (we recommend at least 120 seconds) or use the asynchronous polling pattern described in the Agents guide.
</Note>
